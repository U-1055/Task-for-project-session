# Task-for-project-session
Отборочное задание на проектную сессию 1-7 апреля 2026 г.

# Установка
Требуется **Python 3.12.3** и зависимости в **requirements.txt** (только для Задания 2).
Для Задания 1:
1. Клонируйте репозиторий, скачайте код или отдельно файл **fib.py**.
2. Запустите **fib.py** с указанной версией интерпретатора.

Для Задания 2:
1. Клонируйте репозиторий\скачайте код.
2. Создайте виртуальное окружение.
3. Выполните `pip install -r requirements.txt`
4. Запустите файл **main.py**
   
ИЛИ вы можете скачать ZIP-архив tlibrary на странице релиза, распаковать его и запустить **main.exe**

# Задание 1 (Поиск чисел Фибоначчи в заданном диапазоне)
Файл - **fib.py**.
Клонируйте репозиторий, скачайте код или отдельно файл **fib.py**.
Запустите его с помощью указанной версии **Python**.
Ввод и вывод в форматах, указанных в примерах к заданию:
`5 50` -> `5 8 13 21 34`

# Задание 2 (Консольное приложение Т-библиотека)

Реализованы следующие функции:
1. Создание, удаление и полноценное редактирование книг
2. Просмотр книг с фильтрацией по статусу (прочитано/непрочитано) (в т.ч. в разделе "Избранное")
3. Добавление в Избранное и удаление из него
4. Поиск книг по ключевым словам в названии, авторе и описании
5. Рекомендация книг на основе частоты автора и жанра в библиотеке - рекомендуются книги, которые имеют такой же жанр или автора, как и большинство книг в библиотеке.
6. Добавление авторов и жанров и выбор их из списка при редактировании книги
7. Сохранение книг, жанров и авторов в БД на SQLite через SQLAlchemy.

Кроме того, слой доступа к данным покрыт автотестами с помощью pytest.
